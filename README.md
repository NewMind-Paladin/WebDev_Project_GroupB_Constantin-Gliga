# WebDev_Project_GroupB_Constantin-Gliga

## Website Description

This project is a website for a winter activities and trips agency. Visitors can explore the agency, browse winter activities, read a winter story, and find contact information.

## Project Structure

- `index.html` - homepage and winter story
- `about.html` - information about the agency
- `activities.html` - winter activities
- `contact.html` - contact information and message form
- `styles.css` - shared site styles, including responsive layouts
- `images/` - logos, page hero images, and the shared winter mountain background

## Viewing the Website

Open `index.html` in a web browser. Use the navigation bar to visit the other pages. The pages share `styles.css` and use images stored in the `images/` folder.
