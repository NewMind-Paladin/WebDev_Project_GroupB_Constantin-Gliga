# WebDev_Project_GroupB_Constantin-Gliga

## Website Description

This project is a simple website for the winter trips agency. The homepage includes a navigation bar with Home and About links, a main title, and a short introduction about Lucas Snow and his story. The design is minimal and easy to expand, making it a good starting point for a personal story or adventure-themed web page.

## Project Structure

- index.html - homepage
- about.html - about page
- contact.html - contact page
